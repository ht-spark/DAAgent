# 输入框下方 token 消耗展示

范围：仅设计输入框下方右侧的新增统计。保留现有项目上下文、输入框、模型选择、发送按钮和左侧提示的视觉语言。

口径：最近一轮运行的实际输入、输出和总 token；后台完成后更新。示例 9,760 输入、2,720 输出、12,480 合计只用于预览，不代表真实消耗。缺失时显示“用量未知”，运行中显示“统计中…”，未运行显示“暂无用量”。

三版统一采用相同内容、尺寸与项目配色。桌面展示于现有提示行右侧；移动端允许提示和统计分行，统计仍靠右。统计不是上下文窗口占用率，也不估算当前输入文本。

形式来自内容：token 是辅助计量，保持页脚层级；输入与输出以文字或细分条表达其组成。
