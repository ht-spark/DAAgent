# 已选定方向

用户原话：“B，既有本论对话任务的统计，同时有整个会话框内分的统计”。

选择：B 平铺明细。参考预览：dir-2.html、dir-2.jpg、comparison.jpg。

实施约定：输入框下方右侧按两行显示“本轮任务”和“整个会话”，每行分别显示输入、输出、合计 token。会话累计来自当前会话的助手运行记录，按运行 ID 去重。运行中本轮显示统计中，累计显示已结束任务；未知数据保留未知，有已知小计时以“≥”提示下界。历史加载与运行完成均更新统计。

后续调整：用户要求删除 Enter/附件说明，把两组统计放在输入框下方同一行，并靠近页面底边。桌面采用一行右对齐，窄屏允许换行；输入框下间距 4px、底部留白 6px。
