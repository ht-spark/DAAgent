五组优先改进：

1. **[P1] 加深次级文字，统一颜色和动作层级。** 实测输入区占位文字对比度约 3.65:1、项目标题约 3.59:1；技能上传按钮白字与底色按源码计算约 3.21:1，需复核最终样式。正常小字号文字偏淡，侧栏加减按钮又叠加 0.55 透明度，操作不易发现。建立主文字、次文字、辅助文字三档可读色，以及主操作、次操作、危险操作的统一样式；品牌绿可用于关键操作和当前选择，灰色阴影减轻。全局蓝色 primary 与聊天局部暖灰变量应归并到语义 token，再保留必要的局部值。位置：[全局令牌](D:/DAAgent/web/src/index.css:11)、[聊天局部令牌](D:/DAAgent/web/src/forms.css:6379)、[占位文字](D:/DAAgent/web/src/forms.css:7073)、[技能上传按钮](D:/DAAgent/web/src/forms.css:7338)、[项目操作](D:/DAAgent/web/src/forms.css:10138)。建议：`$impeccable colorize`、`$impeccable typeset`，最后 `$impeccable polish`。

2. **[P1] 窄屏导航遮住内容，设置分类消失。** 390×844 实测顶部导航约 199px 高，而正文只预留 64px；技能页标题与上方操作被遮挡。720px 以下设置导航直接隐藏，常规页无法通过可见分类入口切到 API 配置。将窄屏侧栏改为明确开合的导航抽屉，或保证顶栏实际高度与正文占位一致；设置改成横向标签或分类选择器。桌面保留现有侧栏结构。位置：[窄屏导航](D:/DAAgent/web/src/forms.css:4478)、[正文占位](D:/DAAgent/web/src/forms.css:4491)、[隐藏的设置分类](D:/DAAgent/web/src/forms.css:10036)。建议：`$impeccable adapt`。

3. **[P1] 补齐空态、上传入口和弹窗的操作反馈。** 零知识库时，空选择器旁仍展示醒目的上传邀请；代码检查知识库为空便不执行点击操作。应先展示“创建知识库”的可执行空态，创建后显示上传区，并提供原生“选择文件”按钮作为键盘入口。弹窗虽有 Tab 循环，实测打开后焦点仍留在背景按钮，关闭后可能回到 BODY；共享模态层没有保存触发器或初始聚焦/恢复逻辑。应在共享层补齐打开、嵌套与关闭焦点。输入框还应增加持久的程序化名称。位置：[知识库选择与上传](D:/DAAgent/web/src/pages/KnowledgeBase.tsx:256)、[点击门槛](D:/DAAgent/web/src/pages/KnowledgeBase.tsx:291)、[共享模态层](D:/DAAgent/web/src/modalLayer.ts:132)、[聊天输入框](D:/DAAgent/web/src/pages/NewChat.tsx:1899)。建议：`$impeccable onboard`、`$impeccable harden`。

4. **[P2] 首页留白缺少任务引导与交付预期。** 当前首屏主要是图标、“今天想分析什么？”和底部输入框，无法充分解释本产品的建模价值。保持简洁，在标题与输入区之间增加两三个可编辑的任务示例、一句附件说明和交付预期，例如模型说明、计算过程、结果与报告。示例来自不同领域，提供问题入口，不绑定算法或固定建模流程。显示当前项目及资料状态，让开始前的上下文更清楚；将“MeritModel 关闭”明确为“模型名 · 思考：关闭”。位置：[首页空态](D:/DAAgent/web/src/pages/NewChat.tsx:1813)、[模型标签](D:/DAAgent/web/src/pages/NewChat.tsx:2214)。建议：`$impeccable onboard`、`$impeccable layout`。
